**完成后谁收到提醒，取决于版本。** 在 `fdfbfcd`，成员亲自发起的 Run 正常完成且 Issue 仍开放时，监听器会向该发起人投递带 Run 引用的 `agent_completed` 提醒，受通知资格约束。上游用例专门区分发起人、负责人、创建人和由 Agent 代为委派。随后上游撤回分区 Inbox，`bf25e5a` 已将 Inbox 纳入 Work 面板；该版监听器不再因 Run 成功结束单独发这一条通知。业务上要请林接受订单，可以把对应工作流步骤交给林。完成提醒的收件人和林接受的候选、标准是两件分别记录的事。[固定版完成回流](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/cmd/server/notification_listeners.go#L421-L470) · [固定版用例](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/cmd/server/inbox_sections_test.go#L353-L393) · [上游撤回提交](https://github.com/multica-ai/multica/commit/ac0e806d9cf72ffd8c6f3d16242d7782012a5aa7) · [后续通知实现](https://github.com/multica-ai/multica/blob/bf25e5a7e7da031300427586668c2d0ff35fb7af/server/cmd/server/notification_listeners.go#L1189-L1205)

**指定一位人工业务联系人。** Issue 已有 Creator、Requester 与 Assignee。Requester 只在可追到直接人工发起的特定创建路径有值；Run 的 `AccountableUserID` 另有审计归因语义。若需在整个 Issue 单列一个人，现有单值 `actor` 属性支持工作区成员引用，写入时校验成员。通用属性值可由有相应访问权的成员或 Agent 修改。记录人选可复用这项配置；若要限制谁能改任，或要求指定人接受某版交付，还需针对相应业务动作核对权限与决定。[请求者取值](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/pkg/db/queries/issue.sql#L798-L807) · [Run 归因](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/internal/attribution/attribution.go#L148-L161) · [属性写入约定](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/internal/handler/property.go#L28-L40) · [成员引用校验](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/internal/handler/property.go#L311-L333)

**订单约定由林接受时。** 可用原工作流把父 Issue 交给林，并对这一项关闭原生 PR 自动完成。上游合并处理会检查关联 PR、目标状态和该 Issue 的设置，然后直接更新状态。本项目已约定林按现行规则 D2 接受候选 C2；若保留由 PR 合并触发完成的入口，该入口也需要核对林作出的这次决定。[PR 自动完成条件](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/internal/handler/pr_auto_complete.go#L173-L242) · [状态更新](https://github.com/multica-ai/multica/blob/fdfbfcd5e5d30c135255e63ab9af4c52672b7bbc/server/internal/handler/pr_auto_complete.go#L280-L318) · [订单的完成规则](../architecture/01-unified-work-lifecycle.md#62-状态推进与负责人交接)
